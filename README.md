# MachineGuard

MachineGuard is a predictive maintenance project built around the NASA IMS Bearing Dataset.

The goal is to build an end-to-end machine learning system that processes vibration data, detects mechanical degradation, and progressively adds production ML components such as experiment tracking, APIs, databases, testing, containerization, and deployment.

## Current phase

Phase 0 — Project setup.

## Planned first milestone

Load one NASA IMS vibration file, understand its structure, and reproduce a vibration plot from the raw data.
